# An Roastery — Admin product context

## Users
Staff at the cafe: Admin, Cashier, Waiter. They run the floor during a shift — not marketing visitors.

## Product
React admin for An Roastery coffee shop. Talks to the CoffeeShop ASP.NET API (`/api/...`): auth, dashboard, orders/kitchen, tables, menu, inventory, customers, payments, reports, users, shift.

## Surface mode
**Operate** — task UI. Scanability and real cafe workflow beat decorative expression.

## Brand
- Name: An Roastery
- Palette: `#2b1d14` (deep brown), `#f5ecdf` (cream), `#b5835a` (caramel)
- Type: Cormorant Garamond or Playfair Display for titles; one clean sans for UI (not Inter)
- Tone: warm, quiet, craft — film grain OK; no purple/indigo gradients, no emoji icons, no identical card grids

## Avoid
AI-default looks: purple-on-white, cream+terracotta cliché stacks, broadsheet hairlines, SaaS pill clusters, multi-layer shadows, rounded-full everything.
